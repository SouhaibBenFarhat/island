Why it exists

Stop retyping the same twelve things.

Your address, your signature, a ticket prefix, the standup template, that one long command. They live in a note you have to go and find, so you type them from memory instead. Island keeps them on screen and one click away — and the click lands in whatever field you were already writing in.

One click, any app

Mail, Slack, a browser form, a terminal. Island never takes focus, so the text goes exactly where your cursor was.

Floats everywhere

Drag it anywhere, on any Space, over full-screen apps. Collapse it to a small pill when you want the pixels back.

Placeholders

Write {{date}} or {{clipboard}} in an item and it's filled in the moment you click — not when you saved it.

Native & tiny

SwiftUI end to end. No Electron, no background service farm — a one-megabyte app that feels like part of macOS.

How it works

Honest plumbing

  1. 1.The bar is a non-activating panel. Clicking it doesn't switch apps, so the field you were typing in keeps the keyboard.
  2. 2.Island puts the item's text on the clipboard, sends ⌘V, then puts your old clipboard back. Prefer it untouched? Switch to typing the text out key by key.
  3. 3.Placeholders are expanded at click time, so {{date}} is today's date, every day.

macOS asks for Accessibility permission once — that's what lets any app send keystrokes to another. Your items live in a plain JSON file on your Mac. Nothing is uploaded, and Island has no network code at all.

Install

Up and running in one command

# install

brew install --cask souhaibbenfarhat/tap/island

# upgrade

brew upgrade --cask island

# uninstall

brew uninstall --cask island

# installed manually from the zip instead? clear Gatekeeper's

# quarantine flag once, so the app opens without a "damaged" warning

xattr -dr com.apple.quarantine /Applications/Island.app

On first launch, macOS asks to allow Island under Privacy & Security → Accessibility. Without it the app can't put text into other apps. Island isn't notarized by Apple (it's ad-hoc signed) — the Homebrew cask clears the quarantine flag for you on install, so the xattr line is only needed if you download the zip from GitHub Releases yourself. Either way, you can always audit the source.
